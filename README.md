# Proyecto-3

Este proyecto se enfoca en el uso de un módulo Bluetooth para permitirle a un Arduino conectarse inalámbricamente con una computadora, permitiéndole a esta última prender y apagar el foco integrado del Arduino.

Se tuvo un problema con el módulo de Bluetooth, por lo cual no fue posible obtener resultados (no se incluye un video). Tampoco se incluye un diagrama del circuito dado a que todos los equipos siguieron el mismo circuito (además de que este no puede ser generado mediante TinkerCAD).

CORRECCIÓN: ¡YA SE PUDO! WOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOOO. Resulta que el módulo estaba en perfectas condiciones. El que estaba mal era el operador jajajaja.
